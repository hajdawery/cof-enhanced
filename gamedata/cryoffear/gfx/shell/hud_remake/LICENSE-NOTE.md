# Remake HUD icon provenance

These four standalone icons (heart, bullet, magazine, shell) and the sixteen-cell item atlas were generated for Cry of Fear: Enhanced on2026-09-27 using the built-in image generation tool. They are new monochrome pictograms, not extracted from Cry of Fear or the cancelled remake. The remake screenshots informed HUD placement only.

Distributed with this project under GPL-3.0-or-later to the extent copyright applies; see the repository LICENSE. No third-party game artwork is included.

Generation briefs: transparent monochrome anatomical heart with simple interior cuts; upright single rounded-nose cartridge with rimmed base; slightly angled pistol magazine with three witness holes; short stout flat-top shotgun shell with rimmed base. All prompts required no lettering, background, shadow or realistic texture and legibility at about20–24screen pixels. Sources are retained unchanged; the renderer fits their alpha bounds to the HUD icon slot.

The transparent item atlas contains flashlight, mobile phone, camera, lantern, knife, baton, branch, sledgehammer, flare, radio, axe, book, syringe, hand, pickaxe and shovel, in that row-major order. Generated on 2026-09-27 from an original 4-by-4 monochrome silhouette brief. The source PNG is unchanged; code crops each cell to its alpha bounds.
