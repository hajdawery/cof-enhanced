// Gamepad button icons for the menu's Gamepad controls page and, later, the
// in-game "press (A)" hints. One button per line:
//
//   <engine key> <xbox icon> <ps5 icon> <xbox label> <ps label>
//       <xbox u> <xbox v> <ps5 u> <ps5 v> <marker size>
//
// engine key   the key name the engine binds (engine/client/input/in_keys.c)
// icons        files under gfx/shell/gamepad/, Zacksly's "Buttons Full Solid"
//              white 128 px icons (CC BY 3.0, see LICENSE-Zacksly.txt)
// labels       the button's printed name on that pad (hint stage; the menu
//              page names its rows itself, through the menu string tables)
// u v          centre of the button on <pad>/controller.png, as fractions of
//              the picture's width and height (v < 0: above the picture, where
//              the triggers sit in this front view)
// marker size  the page's marker, as a fraction of the picture's width
//
// Written by hand from the pictures made by scripts/make-gamepad-assets.py
// (xbox 1024x726, ps5 1024x692).
//
// Styles (cof_pad_style 0..3 = xbox, ps5, switch, steamdeck; -1 = Auto, the
// style of the pad in use, published by the engine as cof_pad_style_auto).
// The ten-column lines above are the xbox and ps5 styles. Further lines, any
// order:
//
//   "STYLE" <style id> <controller picture>
//   <engine key> <style id> <icon> <label> <u> <v> <marker size>
//
// A key with no line for a style falls back to its Xbox icon and label; a
// style without a STYLE line falls back to the Xbox picture (markers then at
// the Xbox u/v). The engine keys are POSITIONS on every pad (A_BUTTON = the
// bottom face button, B_BUTTON = right, X_BUTTON = left, Y_BUTTON = top; the
// engine makes SDL report Nintendo pads by position, cof_pad_positional), so a
// Nintendo pad's A_BUTTON is the button printed "B": its line shows the Xbox
// "B" letter at the bottom of the Joy-Con. switch/ and steamdeck/ are haej's
// art (some icons derived from Zacksly's CC BY 3.0 icons, see
// LICENSE-NOTE.md), made by scripts/make-gamepad-style-art.py (switch
// 1024x1015, steamdeck 1024x592); u/v measured on those pictures. Steam Deck
// extras (MODE = STEAM, MISC_BUTTON = the Quick Access "..." button,
// PADDLE1..4 = R4, L4, R5, L5, SDL's names for the back grips) only arrive
// when the game reads the Deck's own controller (outside Steam Input or with
// a template that passes them); Steam keeps STEAM and "..." for itself.
