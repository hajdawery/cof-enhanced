# Licensing

This page says, in plain language, what in this repository belongs to whom,
which licence covers each part, and what a release of Cry of Fear: Enhanced
has to contain to meet those licences. It is not legal advice. The licence
texts themselves are in [`LICENSE`](LICENSE) and [`licenses/`](licenses/),
and every third-party copyright line is in
[`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md).

## 1. The short version

- **Our code** (the patches, the scripts, the launcher, the tests) is

- **The engine we patch** is Xash3D FWGS. Its own source files are
  GPL-3.0-or-later (some older Quake-derived files are GPL-2.0-or-later,
  which may be used under version 3). Because our patches modify it, and
  because we ship binaries built from it, our patches *have* to be GPL too.
  That is why the repository licence is GPL-3.0-or-later and not something
  more permissive.
- **Fonts**: Inter and the bitmap atlases we generate from it are under the
  **SIL Open Font License 1.1**, not the GPL.
- **Language packs** (`languages/`) are **not** under the GPL. They are
  translated game text and translated signage derived from Team
  Psykskallar's game, contributed by the translators with permission, and
  distributed only for use with a legally owned copy of Cry of Fear. See
  [`languages/polish/LICENSE-NOTE.md`](languages/polish/LICENSE-NOTE.md).
- **Cry of Fear itself** (its DLLs, maps, models, sounds, textures, text and
  every other file) belongs to Team Psykskallar and is **not** in this
  repository and not in any release. Valve's Half-Life SDK headers that the
  engine compiles against carry Valve's own terms (section 5).

## 4. What the licences require of us, and how we meet it

### GPL-3.0-or-later (Xash3D FWGS, mainui_cpp, our patches)

`xash.dll`, `ref_gl.dll` and `menu.dll` are GPL works we modified;
`filesystem_stdio.dll` is a GPL work we ship unmodified (the same
obligations apply to it, except marking changes). Shipping them obliges
us to:

1. **License our changes under the same terms.** Done: `LICENSE` is
   GPL-3.0-or-later and every new GPL-side file carries the GPL notice.
2. **Provide the Corresponding Source** (GPLv3 section 6) for exactly the
   binaries we ship: the upstream commits in section 3, our patches and
   apply scripts at the release's commit, and the build configuration
   above. We use section 6(d): the source is offered from the same place
   as the binaries (the GitHub release) with clear directions. Because
   upstream repositories can move or vanish and section 6(d) makes *us*
   responsible for keeping the source available, **every release must
   also attach a source archive** of the patched trees (see section 6).
3. **Keep every copyright and licence notice intact**, in source and in
   the release, and **ship the GPL text** with the binaries.
4. **Mark our changes** (section 5(a)): the patches themselves are the
   record, and each new file names the project.
5. **Add no further restrictions** and charge nothing for the licence.
   Releases are free of charge.

GPLv3 section 5(d) (Appropriate Legal Notices in an interactive UI) does
not oblige us to add a notice screen, because upstream Xash3D FWGS does not
display one. The menu's Credits page is a good place for a line naming
Xash3D FWGS, mainui_cpp and FreeVGUI anyway.

### BSD-3-Clause (FreeVGUI, MiniUTL, the Xiph libraries, getopt)

Binary redistribution must "reproduce the above copyright notice, this list
of conditions and the following disclaimer in the documentation": ship
`THIRD-PARTY-NOTICES.md` and `licenses/`. The names of the copyright
holders (FreeVGUI's authors, Valve, the Xiph.Org Foundation, the University
of California) must not be used to endorse or promote this project.
Our FreeVGUI changes are offered under the same BSD-3-Clause licence.

### MIT / zlib / public domain (stb_truetype, miniz, MultiEmulator, whereami, SDL2, library-suffix, vgui_api.h)

Keep the copyright and permission notices with the binaries (done by
`THIRD-PARTY-NOTICES.md`). SDL2 is shipped unmodified, so the zlib
licence's "altered versions must be plainly marked" clause does not apply.

### LGPL-2.1 (the compact mpg123 files inside the engine)

`engine/client/soundlib/libmpg/` carries mpg123 files under LGPL-2.1. They
are compiled into the GPL engine, which LGPL-2.1 section 3 permits; the

### SIL Open Font License 1.1 (Inter and our atlases)

- `OFL.txt` must travel with the fonts **and** with the generated atlases.
  It is in `gamedata/cryoffear/gfx/fonts/` and `gamedata/cryoffear/fonts/`;
  the patcher must install both copies.
- The fonts may not be sold by themselves. They are bundled with free
  software, which the OFL allows.
- Inter declares **no Reserved Font Name** (its copyright line has no "with
  Reserved Font Name" clause), so the OFL does not force a rename. The
  font's name table does record "Inter UI and Inter is a trademark of rsms",
  so our derived atlases are named `cof_console*` / `cof_hudtext*` and must
  not be presented as "Inter" themselves; describing them as "generated
  from Inter" is fine.
- The atlases are a Modified Version and stay under the OFL; they may not
  be relicensed under the GPL.

Free of charge and non-commercial only.

## 5. Things that are not a clean fit

1. **Valve SDK headers inside GPL binaries.** Xash3D FWGS compiles Valve's
   Half-Life SDK headers (`common/*.h`, `engine/eiface.h`, `engine/edict.h`,
   `engine/progdefs.h`, `pm_shared/*.h`, mainui's `sdk_includes/`) into the
   engine, `ref_gl` and the menu. Their notice reads, verbatim:
   "Use, distribution, and modification of this source code and/or
   resulting object code is restricted to non-commercial enhancements to
   products from Valve LLC." (`licenses/valve-hlsdk-header-notice.txt`;
   Valve's newer Half-Life 1 SDK licence, `licenses/valve-half-life-1-sdk-LICENSE.txt`,
   similarly allows distribution "but only for free"). A non-commercial
   restriction is an additional restriction the GPL does not allow, so the
   combination is not cleanly GPL-compatible. This is inherited from
   upstream Xash3D FWGS, which distributes its own binaries the same way,
   and we cannot fix it. What we do: distribute free of charge, never sell
   or bundle anything commercially, keep Valve's notices, and treat Cry of
   Fear (a free GoldSrc game on Steam) as the Valve-engine product being
   enhanced. Anyone who wants to sell or commercially bundle a build must
   not.
2. **The engine loads proprietary game DLLs.** `xash.dll` loads Team
   Psykskallar's `client.dll` and `hl.dll` at run time. The GPL governs
   what we distribute, not what the user runs; we distribute none of the
   game's DLLs, and loading mod DLLs is the upstream engine's designed use.
3. **Our new files' copyright lines.** Several new files carry the licence
   notice but no copyright line (`cof_language.*`, `Theme.*`,
   `CryOfFear.*`, `CoFCoop.cpp`, `cofscale.cpp`, `coffont.*`) and
   `sv_cof_cheats.*` says "Copyright (C) 2026 cofenhanced". They are
   covered by this repository's `LICENSE` and copyright line; adding
   "Copyright (C) 2026 haej (Cry of Fear: Enhanced contributors)" to each
   new file at the next patch regeneration makes that explicit, and is
   what BSD-3-Clause's "above copyright notice" expects for the FreeVGUI
   files.

## 6. What every release (and the patcher) must contain

The release archive, and whatever the patcher installs, must include:

1. `LICENSE` (the GPL-3.0 text with our notice) and `licenses/` in full.
2. `LICENSING.md`, `THIRD-PARTY-NOTICES.md` and `DISCLAIMER.md`.
3. `OFL.txt` beside the Inter fonts and beside the `.fnt` atlases.
4. For each language pack: its `README.md` and `LICENSE-NOTE.md`.
5. The player README built from
   [`docs/player-README-template.md`](docs/player-README-template.md)
   (disclaimer, attribution, source offer).
6. A **source offer** (`SOURCE.txt` or the player README section) naming:
   - this repository, <https://github.com/hajdawery/cof-fix>, and the exact
     commit the release was built from;
   - every upstream commit in section 3 that was used;
   - the build configuration in section 3.
7. A **source archive** attached to the same GitHub release
   (`cofenhanced-<version>-source.zip`): the patched engine tree with its
   submodules at the "used" commits, plus this repository at the release
   commit. This keeps section 6(d) satisfied even if an upstream
   repository disappears, for as long as the binaries are offered.

The patcher must also:

- back up, never delete, the game files it replaces (`CoFLaunchApp.exe`,
  `vgui.dll`, `FileSystem_Stdio.dll`), and restore them on uninstall;
- never download, copy or redistribute any Cry of Fear or Steam file; work
  it needs from game data (the `.ent` override for the menu map, for
  instance) is generated on the player's machine from the player's own
  install.

## 7. What is never in the repository or a release

- No Cry of Fear or Team Psykskallar assets: no DLLs, EXEs, maps, models,
  sounds, music, textures, videos, fonts or text files from the game,
  except the translation data in `languages/`: the community translation
  packs (text, subtitles, translated signage and interface graphics),
  limited to translator-authored content.
- No modified or patched copies of the game's DLLs (`client.dll`, `hl.dll`)
  or of Valve's (`hw.dll`, `vgui.dll`, `FileSystem_Stdio.dll`). Our
  compatibility work is done in the open-source engine at run time.
- No Steam files (`steam_api.dll`, `steamclient.dll` and so on).
- No build output (`.dll`, `.exe`, `.pdb`), dumps, saves or screenshots in
  git; binaries are published only as release assets.
