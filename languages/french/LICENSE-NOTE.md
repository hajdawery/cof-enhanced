## What this pack is

A **minimal pack**. It holds no text, image or other data from Cry of Fear:

- `strings/menu-strings.tsv` translates **the project's own menu strings**
  (the main menu, the Options pages, Extras, Unlockables, Credits, Save/Load,
  the pause, death and co-op pages, dialogs and the Controls list: text the
  project wrote) into French (Français). It was **machine-drafted** on
  2026-09-22 by an AI worker of the project, not by a translator, and waits
  for review by a native speaker.
- `manifest.txt`, `README.md`, `MANIFEST.tsv` and this note are project files.

The game's own French text (subtitles, notes, documents, intro cards) is
**not** in this folder and is not covered by this note. It ships with Cry of
Fear, belongs to Team Psykskallar, and stays in the player's own installation;
the pack only tells the game to use it (client subtitle slot
`cof_subtitlelanguage 3`).
