# Cry of Fear Spolszczenie (Polish localisation)

This pack is a native, engine-loadable Polish (Polski, code page 1250)
language pack for Cry of Fear, generated by
[`scripts/polish/build_all.py`](../../scripts/polish/README.md) from the
canonical game and a source fan translation. See
[`languages/README.md`](../README.md) for the language-pack format and the
planned (not yet implemented) engine consumer side, and
[`scripts/polish/README.md`](../../scripts/polish/README.md) for the full
format spec, the manifest fields and the engine citations.

## Creators

- **Avioo** (Tłumaczenie, grafiki, testowanie)
- **Mixdedemon** (Tłumaczenie)
- **hexag0n** (Technikalia, testowanie)
- **Izonka** (Testowanie)

## Source and permission

The translation is derived from the fan mod **Cry of Fear: Spolszczenie**,
published on the Steam Workshop:
<https://steamcommunity.com/sharedfiles/filedetails/?id=3164091802>.

It was incorporated into this repository with the Polish localisation
team's explicit permission (green light received 2026-09-22). This pack
ships only translation *data* re-derived from that mod, as a licensed
exception to this repository's general no-game-assets policy — not a copy
of the mod itself.

## What was taken and how it was transformed

The mod ships as a full standalone install (binaries, repainted fonts, a
replacement startup video, full BSPs, full DLLs/EXEs). Nothing here is a
copy of that install; every part was extracted, filtered and re-derived
into a form the engine can mount as an overlay:

- **`txt/`** — subtitle, hint, note and phone-message text, **re-slotted**
  into the game's own `txtfiles/languages/polish/` and
  `notes/languages/polish/` folder convention (the mod instead overwrote
  the root English files). Converted from the mod's Windows-1250 bytes,
  with two encoding anomalies repaired at generation time.
- **`inventoryitems/`** — the same re-slotting and Windows-1250 handling,
  mirroring `cryoffear/inventoryitems/` (including `ammo/`, `weapons/`).
- **`maps/`** — **entity-string overrides generated** instead of shipping
  the mod's recompiled maps: every map was diffed against canonical,
  changed entity key/value pairs extracted (1,345 across 102 maps, 4
  excluded as asset file paths rather than display text), and a per-map
  `.ent` override built and re-parsed to confirm identical entity counts,
  classnames and targetnames to canonical. Zero recompiled BSPs are
  shipped.
- **`textures/`** — sign and poster textures **extracted as loose
  overrides**, one TGA per unique texture name (verified cross-map
  identical), rather than the mod's repainted BSPs.
- **`overlay/`** — UI textures and models carried forward as **same-path
  overlays**: verbatim byte-for-byte copies of the mod's changed TGAs and
  MDLs at their original path relative to the mod root.
- **`strings/dll-strings.tsv`** — the ~235 strings the mod's DLL binary
  patches changed, recovered as an **English -> Polish string table**
  instead of shipping patched DLLs, so the engine can substitute them at
  draw time.

**Deliberately not included:** the mod's binaries (DLLs and EXEs), its
repainted fonts, and its startup video. The DLLs/EXEs are excluded because
this pack is data-only — the planned consumer side substitutes strings and
redirects file reads at runtime instead of shipping patched binaries. The
repainted fonts are excluded because they paint Polish glyphs into the
fixed 256-cell slots of the base game's bitmap font strips, which conflicts
with this project's code-page-aware Inter rendering plan. The startup video
is excluded as a 118 MB asset replacement outside this pack's scope
(translation data), not a translation.

## Data-quality notes

**9 rows in `strings/dll-strings.tsv`** contain a diacritic letter that is
a valid Windows-1250 decode of the mod's raw patch byte but is not the
intended Polish letter (e.g. `ú î ä ë ç Á ô` instead of `ś ł ą ę ć` etc.).
The mod's own patcher used a non-standard byte mapping chosen to match
glyph slots in the game's own bitmap font atlas rather than real
Windows-1250, so the same byte renders correctly in the mod's custom font
but decodes to the wrong letter under a strict cp1250 decode. This pack
always uses the strict, standards-based decode, so these 9 rows are
technically correctly decoded but read as garbled Polish and are pending
retranslation by the project from the `english` column rather than trusting
the `polish` column as shipped:

| file_offset | source_dll | english | polish (as decoded) |
|---|---|---|---|
| `0x0014D8CC` | client | Simon's Book | Ksiäôka Simona |
| `0x001AD090` | hl | Your message is too long. Rewrite it! | Wiadomoúç jest za dîuga. Przepisz jä! |
| `0x001B0990` | hl | What the... The door is jammed! | Co do... Drzwi sië zaciëîy! |
| `0x001B85E0` | hl | buckshot | úrut |
| `0x001C3ECF` | hl | Inventory full | Peîny ekwipunek |
| `0x001DBC9C` | hl | Saved | Zapisaç |
| `0x001E3700` | hl | Nothing to look at! | Nic do oglädania! |
| `0x001E5154` | hl | Shotgun | StrzelÁ |
| `0x001E520C` | hl | Axe | Tôú |

**2 rows flagged `identifier-like`** in `strings/dll-strings.tsv` (kept
rather than excluded — they are not in the confirmed exclusion-by-offset
list, but are gameplay identifiers/registration names rather than display
text, pending a decision on whether they should be translated at all):

- `0x001B66D8` (hl): `revolver` -> `rewolwer`
- `0x001B85E0` (hl): `buckshot` -> `úrut`

## Regeneration

This pack is regenerable from the two read-only source trees; nothing here
should be hand-edited:

```
python scripts/polish/build_all.py --lang polish
```

See [`scripts/polish/README.md`](../../scripts/polish/README.md) for what
each generation step does and the run order.

## Verification

Every file under this folder is listed in `MANIFEST.tsv` (path, byte count,
SHA-256), re-derived from disk at generation time. 542 files, 91,480,977
bytes total, verified against `MANIFEST.tsv` when copied into this
repository.
